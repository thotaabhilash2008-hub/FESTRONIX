# Fixes on codex/firebase-database-migration (2026-11-21)

Tested locally with Firebase Auth + Firestore emulators and the Vite /api/functions adapter.

## Fixed
1. **Every individual registration failed** (free and paid). The checkout payload wrote
   `teamDocumentId: undefined` and the finalize step wrote `razorpayOrderId: undefined`;
   Firestore rejects `undefined`, so the request returned 400.
   - `functions/src/index.ts`: `getFirestore().settings({ ignoreUndefinedProperties: true })` at init.
   - `functions/src/paymentFunctions.ts`: omit `teamDocumentId` when empty.
2. **Rate limiter blocked all requests with no client IP** (always 429 "Too many registration
   attempts" in local dev). Now falls back to `request.socket.remoteAddress`.

## Verified working (locally, after fixes)
- Staff login (dean_sac, ECE dept coordinator); wrong password and no-role accounts rejected.
- Create event from admin portal -> status open, `publicEvents` projection written.
- Event shows on public /events page; seat count drops 60 -> 59 after a registration.
- Free solo registration issues a confirmed pass; duplicate roll number is blocked.
- Admin Registrations shows the event with 1 registered.
